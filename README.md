# LibreOffice-wordcount-exclude-footnote-and-bibliography
Adds the ability to exclude footnotes and bibliography from wordcount.


In many citation systems, footnotes and bibliographic references (Biliography, Citation Page, Works Cited etc) are not to be included in the total word count. Libreoffice has no native wordcount that excludes footnotes.

This extension adds the ability to exclude footnotes, and also adds an invisible style called "Bibliography" that does not affect formatting or typesetting, but will all the program to ignore the selection from wordcount (eg, select entire bibliography and select the bibliography style)
